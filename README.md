# SQL-Employee-Hierarchy-Rollup
## Project Overview
This project demonstrates advanced SQL techniques by mapping a company's organizational structure and calculating dynamic salary rollups. 

## Technical Stack
*   **Language:** SQL
*   **Concepts Covered:** Recursive Common Table Expressions (CTEs), Window Functions (`SUM() OVER`), and Self-Joins.
